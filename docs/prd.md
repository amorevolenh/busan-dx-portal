# 부산 AI·DX 지원사업 문의 포털 PRD

## 1. 목적

부산 AI·DX 지원사업 문의 포털은 지역기업과 시민이 부산정보산업진흥원의 지원사업에 대해 문의를 등록하고, 담당자가 문의 목록을 한 화면에서 확인할 수 있도록 제공하는 단일 웹페이지이다.

페이지는 별도 로그인이나 화면 이동 없이 다음 작업을 즉시 수행할 수 있어야 한다.

- 지원사업 문의 등록
- 최근 문의 목록 확인
- 등록된 문의 삭제
- 문의 목록 엑셀 파일 가져오기
- 문의 목록 엑셀 파일 내보내기

첫 화면에서 사용자는 이 페이지가 "부산 AI·DX 지원사업 문의 포털"이며, "지역기업·시민 누구나 부산정보산업진흥원의 지원사업에 문의할 수 있는 창구"라는 점을 바로 확인할 수 있어야 한다.

## 2. 사용자

주요 사용자는 부산 지역 지원사업에 관심이 있는 기업 담당자, 예비 창업자, 재직자, 시민이다. 이 사용자는 지원사업 유형을 선택하고 본인의 이름, 문의 제목, 문의 내용을 입력해 담당자에게 문의를 남긴다.

운영 사용자는 부산정보산업진흥원 또는 지원사업 담당자이다. 이 사용자는 등록된 문의를 최신순으로 확인하고, 불필요한 문의를 삭제하며, 문의 데이터를 엑셀 파일로 내보내거나 외부 엑셀 파일에서 문의 데이터를 가져온다.

사용자는 전문 시스템 사용자가 아닐 수 있으므로 화면은 행정 포털처럼 단순하고 명확해야 한다. 모든 입력 항목, 버튼, 상태 문구는 한국어로 제공한다.

## 3. 핵심 기능

문의 작성 기능은 페이지 상단의 "문의 작성" 영역에서 제공한다. 사용자는 카테고리, 이름, 제목, 내용을 입력한 뒤 "등록하기" 버튼을 눌러 문의를 등록한다.

카테고리 선택 항목은 드롭다운으로 제공하며 다음 순서로 표시한다.

- AI·DX 솔루션 도입
- 데이터·클라우드 바우처
- 교육·인재양성 신청
- 스타트업 입주·창업
- 게임·콘텐츠 제작 지원
- 해외진출
- 기타

이름 입력란은 한 줄 텍스트 필드이며 placeholder는 "홍길동"이다. 제목 입력란은 한 줄 텍스트 필드이며 placeholder는 "문의 제목을 입력하세요"이다. 내용 입력란은 여러 줄 텍스트 영역이며 placeholder는 "문의 내용을 입력하세요"이다. 이름, 제목, 내용은 필수 입력값이다.

문의 등록이 완료되면 새 문의는 목록의 가장 위에 추가된다. 등록 후 폼은 비워지고, 카테고리는 "AI·DX 솔루션 도입"으로 돌아가며, 제목 입력란에 포커스가 이동한다. 새 문의의 작성 시각은 등록 시점으로 저장되며 목록에는 "방금" 또는 상대 시간으로 표시한다.

문의 목록 기능은 페이지 하단의 "문의 목록" 영역에서 제공한다. 목록은 최근 등록된 문의가 먼저 보이도록 작성 시각 기준 내림차순으로 정렬한다. 목록 상단에는 현재 문의 개수를 "총 N건" 형식으로 표시한다.

초기 진입 시 목록에는 다음 5개 예시 문의가 표시되어야 한다.

| 카테고리 | 작성자 | 제목 | 내용 | 상대 시간 |
| --- | --- | --- | --- | --- |
| 교육·인재양성 신청 | 정하린 | AI 활용 교육과정 일정 안내 부탁드립니다 | 재직자 대상 AI 활용 교육과정이 있다면 개강 일정과 신청 방법을 안내받고 싶습니다. | 방금 |
| 게임·콘텐츠 제작 지원 | 박도윤 | Bu:Star 게임 제작비 신청 절차 | Bu:Star 게임 제작비 지원사업의 제출 서류와 심사 절차를 확인하고 싶습니다. | 3분 전 |
| 스타트업 입주·창업 | 김서연 | 센텀 스타트업 입주 자격 문의 | 초기 창업기업도 센텀 지역 입주 지원 프로그램에 신청할 수 있는지 궁금합니다. | 12분 전 |

| AI·DX 솔루션 도입 | 최유나 | AI 솔루션 실증 비용 지원 가능한가요? | 제조 현장에 AI 품질검사 솔루션을 시범 적용하려고 합니다. 실증 비용 지원 여부를 문의드립니다. | 1시간 전 이상 |

상대 시간은 현재 시각과 문의 작성 시각의 차이를 기준으로 표시한다. 1분 미만은 "방금", 1시간 미만은 "N분 전", 24시간 미만은 "N시간 전", 24시간 이상은 "N일 전"으로 표시한다. 상대 시간은 페이지가 열린 상태에서도 30초마다 갱신되어야 한다.

각 문의 항목에는 삭제 버튼을 제공한다. 사용자가 "삭제" 버튼을 누르면 해당 문의는 즉시 목록에서 제거되고 전체 개수가 갱신된다. 삭제 확인 모달은 제공하지 않는다.

엑셀 내보내기 기능은 "엑셀 내보내기" 버튼으로 제공한다. 버튼을 누르면 현재 문의 목록을 작성 시각 기준 최신순으로 정렬해 `.xlsx` 파일로 다운로드한다. 파일명은 `busan-dx-inquiries-YYYY-MM-DD.xlsx` 형식이다. 시트명은 "문의목록"이다. 내보내는 열은 ID, 카테고리, 제목, 이름, 내용, 등록일 순서로 구성한다. 등록일은 `YYYY-MM-DD HH:mm` 형식으로 저장한다.

엑셀 내보내기가 성공하면 문의 목록 상단에 "문의 N건을 엑셀 파일로 내보냈습니다."라는 성공 상태 문구를 표시한다.

엑셀 가져오기 기능은 "엑셀 가져오기" 버튼으로 제공한다. 버튼을 누르면 파일 선택 창이 열리고 `.xlsx`, `.xls`, `.csv` 파일을 선택할 수 있다. 파일의 첫 번째 시트만 읽는다.

가져오기 대상 열은 한국어와 영어 열 이름을 모두 허용한다.

| 데이터 | 허용 열 이름 |
| --- | --- |
| ID | id, ID, 번호 |
| 제목 | title, Title, 제목 |
| 카테고리 | category, Category, 카테고리, 분류 |
| 이름 | author, Author, 작성자, 이름 |
| 내용 | content, Content, 내용 |
| 등록일 | createdAt, Created At, 등록일, 작성일, 생성일 |

가져오기 시 제목, 이름, 내용이 모두 있는 행만 문의로 등록한다. 카테고리가 비어 있으면 "기타"로 등록한다. ID가 없으면 시스템에서 자동 생성한다. 등록일이 없거나 읽을 수 없으면 가져온 시점으로 등록한다. 유효한 문의가 있으면 기존 목록 맨 앞에 추가한 뒤 최신순으로 다시 정렬한다.

엑셀 가져오기가 성공하면 "엑셀에서 문의 N건을 가져왔습니다."라는 성공 상태 문구를 표시한다. 가져올 수 있는 문의가 없으면 "가져올 수 있는 문의가 없습니다. 제목, 이름, 내용 열이 있는지 확인해주세요."라는 오류 상태 문구를 표시한다. 파일을 읽는 중 오류가 발생하면 "엑셀 파일을 읽는 중 문제가 발생했습니다. 파일 형식을 확인해주세요."라는 오류 상태 문구를 표시한다. 엑셀 기능 라이브러리를 불러오지 못한 경우에는 "엑셀 기능을 불러오지 못했습니다. 인터넷 연결을 확인한 뒤 다시 시도해주세요."라는 오류 상태 문구를 표시한다.

모든 사용자 입력 및 엑셀에서 가져온 텍스트는 목록에 표시될 때 HTML로 실행되지 않고 일반 텍스트로 보여야 한다.

## 4. 화면 구성

전체 페이지는 흰색 배경의 단일 화면으로 구성한다. 콘텐츠 최대 너비는 약 1024px이며, 데스크톱에서는 화면 중앙에 정렬하고 좌우 여백을 둔다. 모바일에서는 좌우 20px 정도의 여백을 유지한다.

상단 헤더는 연한 회청색 배경(`#F8FAFC`)과 하단 구분선으로 구성한다. 헤더 안에는 왼쪽에 파란 세로 막대 장식을 두고, 오른쪽에 페이지 제목을 배치한다. 제목은 "부산 AI·DX 지원사업 문의 포털"이며 굵은 큰 글씨로 표시한다. 제목 아래에는 "지역기업·시민 누구나 부산정보산업진흥원의 지원사업에 문의할 수 있는 창구입니다."라는 설명 문구를 표시한다.

본문은 위에서 아래로 "문의 작성" 카드와 "문의 목록" 영역이 순서대로 배치된다. 두 영역 사이에는 약 16px 간격을 둔다.

"문의 작성" 영역은 흰색 카드 형태이며 얇은 회색 테두리, 작은 그림자, 8px 둥근 모서리를 가진다. 카드 상단에는 제목 "문의 작성"과 보조 문구 "지원사업 담당자가 확인할 수 있도록 필요한 내용을 남겨주세요."를 표시한다.

문의 작성 폼의 첫 줄은 데스크톱에서 2열로 배치한다. 왼쪽은 "카테고리" 드롭다운, 오른쪽은 "이름" 입력란이다. 모바일에서는 두 항목을 세로로 쌓는다. 다음 줄에는 "제목" 입력란을 전체 너비로 배치한다. 그 아래에는 "내용" 입력 영역을 전체 너비로 배치한다. 마지막 줄 오른쪽에는 "등록하기" 버튼을 배치한다.

입력 라벨은 진한 회색의 굵은 글씨로 표시한다. 입력 필드와 드롭다운은 높이 44px, 흰색 배경, 회색 테두리, 8px 둥근 모서리를 가진다. 내용 입력 영역은 최소 5줄 높이이며 사용자가 세로 크기를 조절할 수 있다. 입력 필드가 포커스되면 하늘색 테두리와 연한 하늘색 포커스 링을 표시한다.

"등록하기" 버튼은 높이 44px, 진한 파란색 배경, 흰색 굵은 글씨, 8px 둥근 모서리를 가진다. 버튼 텍스트는 "등록하기"이다. 마우스를 올리면 더 어두운 파란색으로 바뀐다.

"문의 목록" 영역은 연한 회청색 배경(`#F8FAFC`)의 박스 형태이며 8px 둥근 모서리와 내부 여백을 가진다. 상단 왼쪽에는 제목 "문의 목록"과 보조 문구 "최근 등록된 문의가 먼저 표시됩니다."를 표시한다. 상단 오른쪽에는 "엑셀 가져오기" 버튼, "엑셀 내보내기" 버튼, 총 건수 배지를 가로로 배치한다. 화면이 좁으면 버튼과 배지는 여러 줄로 자연스럽게 줄바꿈된다.

"엑셀 가져오기" 버튼은 흰색 배경, 회색 테두리, 진회색 굵은 글씨로 표시한다. 마우스를 올리면 테두리와 글씨가 파란 계열로 바뀐다. "엑셀 내보내기" 버튼은 진한 파란색 배경과 흰색 굵은 글씨로 표시한다. 총 건수 배지는 흰색 배경, 연한 하늘색 테두리, 파란색 굵은 글씨로 표시하며 "총 5건"처럼 표시한다.

엑셀 성공 또는 오류 상태 문구는 문의 목록 헤더 아래, 문의 카드 목록 위에 표시한다. 성공 상태는 연한 초록색 배경, 초록색 테두리, 진한 초록색 글씨를 사용한다. 오류 상태는 연한 빨간색 배경, 빨간색 테두리, 진한 빨간색 글씨를 사용한다. 상태 문구가 없을 때는 이 영역을 보이지 않게 한다.

문의 항목은 흰색 카드로 표시한다. 각 카드는 얇은 회색 테두리, 작은 그림자, 8px 둥근 모서리, 16px 안쪽 여백을 가진다. 카드들은 세로로 쌓이며 카드 사이 간격은 약 16px이다.

문의 카드 상단에는 왼쪽에 카테고리 배지와 작성자·상대 시간, 제목을 배치하고 오른쪽에 "삭제" 버튼을 배치한다. 모바일에서는 삭제 버튼이 카드 상단 콘텐츠 아래 또는 오른쪽 공간에 맞게 줄바꿈될 수 있다.

카테고리 배지는 연한 하늘색 배경, 파란색 굵은 작은 글씨, 8px 둥근 모서리를 가진다. 작성자와 상대 시간은 "작성자 · 상대시간" 형식으로 표시하며 회색 작은 글씨를 사용한다. 제목은 진한 검정 계열의 굵은 글씨로 표시한다. 내용은 제목 아래에 배치하고 회색 본문 글씨, 넉넉한 줄 간격으로 표시한다.

"삭제" 버튼은 흰색 배경, 회색 테두리, 회색 글씨의 작은 버튼이다. 마우스를 올리면 연한 빨간색 배경, 빨간색 계열 테두리와 글씨로 바뀐다.

## 5. 디자인 규칙

전체 디자인은 공공기관 지원사업 문의 포털처럼 차분하고 실무적인 인상을 가져야 한다. 장식적인 이미지, 일러스트, 과도한 애니메이션, 마케팅형 히어로 구성은 사용하지 않는다.

기본 글꼴은 Pretendard를 우선 사용하고, 사용할 수 없을 경우 Noto Sans KR, system-ui, sans-serif 순서로 대체한다. 기본 본문 글자 크기는 15px로 한다.

| --- | --- |
| 페이지 보조 배경 | `#F8FAFC` |
| 주요 파란색 | `#1E40AF` |
| 포커스/강조 하늘색 | `#0EA5E9` |
| 기본 텍스트 | slate 계열의 진한 회색/검정 |
| 보조 텍스트 | slate 계열의 중간 회색 |
| 테두리 | slate 계열의 연한 회색 |

모든 카드, 입력 필드, 버튼, 배지는 8px 둥근 모서리를 사용한다. 버튼과 카드에는 아주 약한 그림자만 사용해 정보 구조를 구분한다.

화면의 정보 위계는 제목, 섹션 제목, 라벨, 본문 순서로 명확해야 한다. 헤더 제목이 가장 크고 굵어야 하며, 섹션 제목은 그보다 작지만 굵게 표시한다. 문의 카드 제목은 본문보다 굵게 표시한다.

입력 필드, 드롭다운, 버튼은 키보드 포커스 상태가 시각적으로 분명해야 한다. 포커스 상태에는 파란 계열 테두리 또는 링을 사용한다.

반응형 동작은 다음을 따른다.

- 콘텐츠는 최대 1024px 폭 안에서 중앙 정렬한다.
- 문의 작성 폼의 카테고리와 이름은 데스크톱에서 2열, 모바일에서 1열로 표시한다.
- 문의 목록 헤더는 데스크톱에서 제목 영역과 버튼 영역을 좌우로 배치하고, 모바일에서 세로로 쌓는다.
- 문의 카드의 상단 정보와 삭제 버튼은 데스크톱에서 좌우로 배치하고, 좁은 화면에서는 줄바꿈을 허용한다.
- 긴 제목, 작성자명, 내용은 카드 밖으로 넘치지 않아야 하며 자연스럽게 줄바꿈되어야 한다.

모든 화면 문구는 한국어로 표시한다. 버튼 문구는 "등록하기", "엑셀 가져오기", "엑셀 내보내기", "삭제"를 그대로 사용한다. 섹션 제목과 설명 문구도 본 문서에 적힌 문구를 그대로 사용한다.

## 6. 성공 기준

사용자는 페이지 진입 직후 "부산 AI·DX 지원사업 문의 포털" 제목과 포털 설명 문구를 확인할 수 있다.

사용자는 카테고리, 이름, 제목, 내용을 입력하고 "등록하기" 버튼을 눌러 새 문의를 목록 최상단에 추가할 수 있다.

필수 입력값인 이름, 제목, 내용이 비어 있으면 브라우저 기본 필수 입력 검증으로 등록이 진행되지 않는다.

문의 등록 후 입력 폼은 초기화되고, 카테고리는 "AI·DX 솔루션 도입"으로 돌아가며, 제목 입력란에 포커스가 놓인다.

초기 문의 목록은 5건으로 시작하고, 총 건수 배지는 "총 5건"으로 표시된다.

목록의 문의는 작성 시각 기준 최신순으로 표시된다. 새 문의 등록, 엑셀 가져오기, 삭제 후에도 정렬과 총 건수가 올바르게 갱신된다.

각 문의 카드에는 카테고리, 작성자, 상대 시간, 제목, 내용, 삭제 버튼이 모두 표시된다.

삭제 버튼을 누르면 해당 문의가 목록에서 제거되고 총 건수가 즉시 줄어든다.

"엑셀 내보내기" 버튼을 누르면 현재 문의 목록이 `busan-dx-inquiries-YYYY-MM-DD.xlsx` 파일로 저장되고, 성공 상태 문구가 표시된다.

"엑셀 가져오기" 버튼을 누르면 `.xlsx`, `.xls`, `.csv` 파일을 선택할 수 있으며, 유효한 문의 행이 목록에 추가되고 성공 상태 문구가 표시된다.

엑셀 파일에 유효한 문의 행이 없거나 파일 읽기 오류가 발생하면 목록은 손상되지 않고 오류 상태 문구가 표시된다.

사용자가 입력하거나 엑셀에서 가져온 `<script>` 같은 문자열은 실행되지 않고 문의 카드 안에 일반 텍스트로 표시된다.

데스크톱과 모바일 화면에서 헤더, 폼, 버튼, 상태 문구, 문의 카드가 서로 겹치지 않고 읽을 수 있게 표시된다.
